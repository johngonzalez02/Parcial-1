# CV Web — John Stiven Gonzalez Rivera

Hoja de vida web personal desarrollada con **HTML5**, **CSS3** y **PicoCSS**, como parte del
Parcial I de Programación en Ambiente Web I (Unidad Central del Valle del Cauca).

## Contenido

El sitio incluye las secciones solicitadas:

- Información personal
- Perfil profesional
- Formación académica
- Experiencia
- Habilidades
- Proyectos
- Cursos y certificaciones
- Contacto

## Tecnologías

- HTML5 semántico
- CSS3 (variables, grid, diseño responsive)
- [PicoCSS](https://picocss.com/) como framework base

## Cómo verlo

Abre `index.html` en el navegador.
